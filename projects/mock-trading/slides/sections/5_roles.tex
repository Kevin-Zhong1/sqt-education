\section{Roles in Trading}

\begin{frame}{Trader Roles}
  \begin{sqt:definition}
    Traders make the trading decisions.
  \end{sqt:definition}

  \begin{itemize}
    \item Somewhere on a scale between fully systematic and fully manual
    \begin{itemize}
      \item Systematic: adjusting strategies, closer to research role
      \item Manual: reacting to news, morning macro meeting
    \end{itemize}

    \item In HFT, traders adjust the parameters of autotraders
    \item They also write a lot of random scripts.
  \end{itemize}
\end{frame}

\begin{frame}{Trader Interviews}
  \begin{itemize}
    \item Mental math (OA)
    \item Probability \& combinatorics (technical interview)
    \item Estimation / trading games (``make me a market on X'')
    \item Python (numpy, pandas)
  \end{itemize}
\end{frame}

\begin{frame}{Researcher}
  \begin{sqt:definition}
    Researchers analyse data of all kinds.
  \end{sqt:definition}

  There is much more to research than just alpha and pricing theory.
  There are a wide variety of research roles across different types of firms (HFT, market makers, hedge funds).

  \begin{itemize}
    \item Analyse past trades to see how the strategy can be improved.
    \item Research trading patterns of counterparties and competitors.
    \item Making interaction (placing and pulling orders) with exchange faster.
    \item Pricing exotics.
    \item Alpha research.
    \item Execution research, transaction cost analysis.
    \item Portfolio optimization, researching correlation matrices.
  \end{itemize}
\end{frame}

\begin{frame}{Researcher Interviews: Core Skills}
  \begin{itemize}
    \item Probability and statistics
    \begin{itemize}
      \item Statistical models, linear regression, generalized linear models
      \item Machine learning, time series
    \end{itemize}
    \item Take home project
  \end{itemize}
\end{frame}

\begin{frame}{Engineering Roles}

  \begin{itemize}
    \item \textbf{Software Engineer}
    \item \textbf{Quantitative Developer}
    \item \textbf{Hardware Engineer}
  \end{itemize}
\end{frame}

\begin{frame}{Software Engineering Roles}
  \begin{sqt:definition}
    \textbf{Software engineers} build the trading/risk/data/research infrastructure \\
    that the trading firm relies upon.
  \end{sqt:definition}

  \begin{itemize}
    \item \textbf{Application Development}
    \item \textbf{UI Development}
    \item \textbf{Data Engineering}
  \end{itemize}

  Sometimes there is a greater focus on
  \begin{itemize}
    \item latency (optimising hotpath)
    \item data throughput
  \end{itemize}
  while in big tech there is a bigger focus on graceful error handling and uptime.
\end{frame}

\begin{frame}{Software Engineering Interviews}
  Skills assessed:
  \begin{itemize}
    \item \textbf{Data Structures \& Algorithms}: implementation, complexity/speed analysis
    \item \textbf{Design Skills}: System design, API design, OOP
    \item \textbf{General Knowledge}: Databases, Networks, OS, Concurrency, Compilers
    \item \textbf{Testing}: Unit tests, mocks, designing for testability
  \end{itemize}
\end{frame}

\begin{frame}{Software Engineering Specialized Tracks}
  Many firms separate candidates into specialized tracks early in the process.

  \vspace{0.3cm}
  \begin{columns}[T]
    \begin{column}{0.5\textwidth}
      \textbf{Low-Latency Track}
      \begin{itemize}
        \item C++
        \item Operating Systems
        \item Networks
        \item Computer Architecture
      \end{itemize}
      \textit{Example firms: Citadel Securities, QRT}
    \end{column}
    \begin{column}{0.5\textwidth}
      \textbf{Python Track}
      \begin{itemize}
        \item Probability and statistics
        \item Data manipulation (Pandas, SQL)
        \item Other stats (machine learning)
      \end{itemize}
      \textit{Example firms: Citadel Securities}
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{Quantitative Development}

  \begin{sqt:definition}
    A \textbf{quant dev} is half developer, half researcher.\\
    They are developers who also contribute to the trading strategies.
  \end{sqt:definition}

  \vspace{0.3cm}
  \textbf{Math/Stats Skills}
  \begin{itemize}
    \item Undergrad math (linear algebra, probability, statistics)
    \item ML techniques (linear regression, clustering, decision trees, gradient boosting)
    \item Python for research (NumPy, Pandas, sklearn, statsmodels, plotting libraries)
  \end{itemize}

  \vspace{0.3cm}
  \textbf{Dev Skills}
  \begin{itemize}
    \item Expected to be as proficient as any other dev
  \end{itemize}

  \vspace{0.3cm}
  \textit{Example firms: Citadel Securities, Optiver}
\end{frame}
